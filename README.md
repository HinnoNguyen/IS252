## NỘI DUNG THỰC HÀNH
<a name="noidung"></a>

Repository này lưu trữ các bài tập thực hành (Lab) và tài liệu trong quá trình học môn **Khai thác dữ liệu (IS252)**:

| Thư mục | Nội dung bài tập | Chi tiết |
|:-------:|:----------------|:---------|
| **[Lab 1](./Lab1)** | **Tiền xử lý và Khám phá dữ liệu (EDA)** | Làm sạch, chuẩn hóa dữ liệu, trực quan hóa và phân tích tập dữ liệu Bank, Titanic, Bất động sản TP.HCM. |
| **[Lab 2](./Lab2)** | **Khai phá luật kết hợp (Association Rules)** | Áp dụng thuật toán Apriori, FP-Growth để tìm tập phổ biến và luật kết hợp trên Groceries, Online Retail. |
| **[Lab 3](./Lab3)** | **Phân lớp dữ liệu (Classification)** | Xây dựng và đánh giá các mô hình phân lớp trên dữ liệu Heart Disease, Wine Quality,... |
| **[Lab 4](./Lab4)** | **Tối ưu hóa & Học sâu (Deep Learning)** | Thuật toán Gradient Descent, các mô hình Deep Learning trong Thị giác máy tính (Faster R-CNN, UNet, CLIP, Localization). |
| **[Lab 5](./Lab5)** | **Phân cụm dữ liệu (Clustering)** | Cài đặt và thực nghiệm các thuật toán phân cụm K-Means, đánh giá chất lượng phân cụm. |
